HALLOW OVERLAY - a see-through stats panel over your games

HOW TO INSTALL
1. Right-click the zip > Properties > tick "Unblock" > OK
2. Right-click the zip > Extract All
3. Double-click INSTALL.bat (no admin needed)

WHAT IT SHOWS
- A big red MIC MUTED warning when your mic is muted in Hallow Mixer, and the song or video that's playing
- "Clip saved" from Hallow Clips and Hallow Hub's break reminder / daily limit, right on the panel
- FPS, 1% and 0.1% lows for the game you're playing (DirectX, Vulkan and OpenGL games), and a frame-time graph with stutters in red
- GPU clocks, power draw and VRAM (NVIDIA cards)
- The game's server: its region, ping, loss and stalls (and the game's up / down traffic if you like)
- Your FPS, ping and the server's region on your phone in Hallow Remote's Live stats tab (never the server's IP)
- Match history: a summary of every game session (FPS, ping, stalls, servers, temperatures), and a one-line summary on the panel when a game closes
- CPU, GPU load and temperature (NVIDIA cards), RAM, ping, session time, the clock
- Only while a game is running (Steam, Battle.net, Epic, EA, Ubisoft, GOG, Riot, Xbox) - or always
- Layout editor: your order, labels, colours, small graphs and text size
- Any corner, one line or a column, three sizes, see-through background - and a different one per game if you like
- Only when something's wrong: stats show up only while they're in trouble (GPU hot, ping high, RAM almost full)
- Packet loss and jitter next to ping
- Ctrl+Shift+O shows or hides it (change it, or any hotkey, in the settings)
- Ctrl+Shift+F9 starts and stops a benchmark: average FPS, 1% and 0.1% lows and a frame-time chart, saved in Documents\Hallow Overlay\Benchmarks
- Optional: a CSV log of every stat while you play (Documents\Hallow Overlay\Logs)
- With Hallow Hub running, Overlay's menu is in Hub's one Hallow icon (turn off "Use the Hallow icon" to keep Overlay's own)

GOOD TO KNOW
- It updates itself: once a day it looks for a new version on GitHub and asks before installing.
- It's its own see-through window: nothing is injected into the game, so it's safe with anti-cheat.
- If it ever crashes, a report is kept on this PC (%APPDATA%\HallowOverlay\crashes) and you're told next time. Nothing is sent anywhere.
- It can't draw over games in exclusive fullscreen - use borderless / windowed fullscreen.
- The Ping stat goes to 1.1.1.1 (your internet connection); the Game server stat pings the game's server. Games that use a relay network (Valve's SDR, for example) show the relay.
